# Ертөнц Бүтээгч v3

Монголоор бичээд англи AI промт автоматаар гаргадаг кино бүтээх өрөө.
v2‑оос ялгаатай нь **автоматжуулалт** ба **10 мянган үгтэй ангилсан толь**.

---

## Юу шинэ болов

### 1. Автомат горим (Алхам 0)
Нэг санаа бичээд **⚡ Ертөнц бүтээх** дарахад Claude дараах бүх ажлыг дараалан хийнэ:

| Алхам | Юу болох |
|---|---|
| Ертөнц зохиох | логлайн, N үзэгдэл, N дүр, N байршил — бүгд монголоор |
| Автомат холбох | үзэгдэл бүрийг дүр, байршилтай нь нэрээр нь холбоно |
| Орчуулга | бүх талбарыг англи руу — **олон талбарыг нэг API дуудлагаар** |
| Кадрын задаргаа | үзэгдэл бүрийг 2–8 кадарт хувааж, камерын заавар өгнө |
| Промт өнгөлөлт | сонгосон хэрэгсэлд (Midjourney / Kling / Higgsfield / Sora) тааруулж дахин бичнэ |

Явцын мөр, алхам бүрийн бүртгэл, **■ Зогсоох** товч бий.

**Лавлагаа зураг.** Санаатай хамт 3 хүртэлх зураг оруулж болно (чирэх,
дарж сонгох, `Ctrl+V`). Claude дүрийн төрх, хувцас, орчин, гэрэл, өнгийг
зургаас, үйл явдлыг санаанаас авна; санаа бичихгүй зөвхөн зураг өгч ч болно.

| | |
|---|---|
| Нягтрал | урт тал ≤ 1568px — апп‑ын бүх загвар бүрэн уншдаг |
| Хэмжээ | зураг бүр ≤ 900 KB (base64); давбал чанар, дараа нь нягтралыг шат дараатай бууруулна — 3 зураг үргэлж проксигийн хязгаарт багтана |
| Формат | JPEG болгож хөрвүүлнэ (тунгалаг дэвсгэр цагаан болно); HEIC зэрэг хөтөч задалж чадахгүй зургийг татгалзана |
| Хадгалалт | зөвхөн энэ цонхны санах ойд — төслийн JSON, localStorage‑д орохгүй |
| Кэш | кэшийн түлхүүрт зургийн хэш ордог тул ижил санаагаар өөр зураг өгөхөд дахин дуудна |

AI холболт шаардлагатай — офлайн толь зураг уншиж чадахгүй.

### 1.4. Seedance 2.5 промт (Алхам 5 → таб)

Промт самбар **📋 Бусад промт** ба **🎬 Seedance 2.5** гэсэн хоёр табтай.
Seedance таб үзэгдэл бүрийг нэг олон кадрын промт болгож угсарна — AI
дуудлагагүй, офлайн ажиллана:

```
[@image1] defines Sarnai's face, hairstyle and wardrobe only — do not copy its background.
[@image2] defines the setting, light and colour palette only — do not copy any people from it.
Format: 5 shots, 15 seconds, 16:9, one continuous take with no cuts (part 1 of 2).
Subject: … · Setting: … · Style: …
Shot 1 (0–3s): slow dolly in, low angle — … Hard cut.
…
Continuity: … · Audio: … · Constraints: …; avoid …
```

- **`[@image1]`, `[@video1]`** лавлагаа промтын эхэнд, дөрвөлжин хаалтанд.
  Дугаар нь файл **хуулах дарааллыг** дагана — блок бүрийн дээр монголоор
  «энэ дарааллаар хавсаргана» жагсаалт гарна (дүрийн зураг, байршлын зураг,
  брэндийн түгжсэн фрэйм, өмнөх клип). Лавлагаа бүр нэг нарийн үүрэгтэй,
  юуг хуулахгүйг заана.
- Нэг үүсгэлт **≤ 15 секунд** — урт үзэгдлийг клипэд хуваана; 2 дахь
  клипээс `[@video1]` = өмнөх клип болж үргэлжилнэ.
- Брэндийн камерын дүрэм «no cuts» бол `Hard cut`‑ийн оронд тасралтгүй шилжилт.
- Сэдэв, орчныг эхэнд **нэг удаа** бичнэ; кадрууд зөвхөн өөрчлөгдөж буй зүйлээ.
- Дүрийн нэрийг галиглана (*Сарнай* → Sarnai); монгол үсэг хэзээ ч орохгүй.
- Сонголт: @ лавлагааг унтраах, камерын хөдөлгөөний бичлэг `[@video]` нэмэх.

Хэлбэр нь нийтлэг гарын авлагуудад (BytePlus, Higgsfield, Kapwing, OpenArt)
үндэслэсэн. Албан ёсны хаалтын бичиглэл: `( )` хөгжим, `< >` дууны эффект,
`{ }` яриа, `【 】` дэлгэц дээрх бичиг.

### 1.5. Брэнд файл — сувгийн гарын үсэг (Алхам 1)

AI таны бодлыг уншиж чаддаггүй. Заагаад өгөхгүй бол хамгийн **ердийн**
хувилбар руу ордог — ердийн зүйл нь түүний хувьд хамгийн аюулгүй таамаг.
Тиймээс сувгийн харагдац, хоолойг нэг удаа бичээд бүх ангид дахин ашиглана.

**Гурван зарчим:**

| Зарчим | Юу хийдэг |
|---|---|
| **Нэг фрэйм дүрэм** | Бүтэн видео үүсгэхээсээ өмнө **ганц зураг** гаргаж стилээ шалгана. Зураг засах нь видео засахаас олон дахин хямд. Таалагдвал «Стиль тогтоосон» гэж **түгжинэ** |
| **Брэнд файл** | Харагдац, гэрэл, палетт, камерын дүрэм, хоолойны өнгө аяс, дуу авианы палетт — нэг дор. Промт болгонд автоматаар шингэнэ |
| **4 давхаргат бүтэц** | Судалгаа → Харагдац → Хоолой → Хяналт. Аль нэг нь дутвал AI өөрөө нөхнө — ердийн зүйлээр |

**Дөрвөн давхарга:**

| # | Давхарга | Агуулга |
|---|---|---|
| 1 | **Судалгаа** | Сувгийн ниш, батлагдсан гарчгийн формат (**хос хэлтэй** — мастер промтод англиар орно), сэдвийн жагсаалт |
| 2 | **Харагдац** | Визуал гарын үсэг, гэрэлтүүлэг, өнгөний палетт, камерын дүрэм, «хэзээ ч гаргахгүй» |
| 3 | **Хоолой** | Өгүүлэгчийн өнгө аяс, хэрэглэдэг/хэрэглэдэггүй үг, дуу авианы палетт |
| 4 | **Хяналт** | «Юу ч үүсгэхээс өмнө чиглэлээ харуул» + AI‑ийн санал болгосон чиглэл — хоёулаа мастер промтын LAYER 4‑т орно |

**Хаана нөлөөлдөг вэ:**

- 2‑р давхарга (харагдац) нь `PR.decorate` дундуур **бүх промтод** нэмэгдэнэ.
  Алхам 5‑ын «Брэнд файлыг бүх промтод шингээх» тэмдэглэгээгээр унтраана.
- «Хэзээ ч гаргахгүй» талбар нь **сөрөг промтод** автоматаар нийлнэ.
- Брэнд контекст нь **Авто горимд** монгол текст зохиох үед AI‑д өгөгдөж,
  промт өнгөлөх үед стилээс гажихаас сэргийлнэ.
- Стиль түгжигдээгүй байхад «⚡ Ертөнц бүтээх» дарвал нэг удаагийн сануулга гарна
  (брэнд файл огт хоосон бол сануулахгүй).

**Түгжээ хуучрах.** Түгжих агшинд харагдацын 4 мөрийн (Харагдац, Гэрэл,
Палетт, Хэзээ ч гаргахгүй) утгыг тэмдэглэж авна. Дараа нь аль нэг нь
өөрчлөгдвөл (гараар, Авто → Брэнд, AI зохиолт) түгжээ **хуучирсан** гэж
тооцогдоно: мөр шар болж өөрчлөгдсөн мөрүүдийг нэрлэнэ, мастер промтод
«LOCKED» гэж бичихээ больж, Seedance‑ийн түгжсэн фрэймийн лавлагаа хасагдана.
«🔒 Шинэ харагдацаар түгжих» эсвэл «🔓 Түгжээ тайлах» товчоор шийднэ.
Өөрчлөлтөө буцаавал (`Ctrl+Z`) түгжээ өөрөө сэргэнэ. Камерын дүрэм
тооцогдохгүй — хөдөлгөөнийг ганц зураг дээр шалгах боломжгүй тул Camera
Director бичсэн ч түгжээ эвдрэхгүй. Англи орчуулгыг гараар засах нь ч
эвдэхгүй (утгын эх нь монгол тал). Camera Director мөн ижил дүрмээр уншдаг.

**Авто → Брэнд.** Авто самбарын **🎨 Брэнд рүү хадгалах** товч брэндийн
**бүх 11 мөрийг** одоогийн утгатай нь жагсаана. Хоосон мөрүүд урьдчилан
сонгогдсон; буруу бичигдсэн мөрийг сонговол улаанаар «дарж бичнэ» гэж
тэмдэглээд зохиосон ертөнц ба лавлагаа зургаас дахин бичнэ. Сонгоогүй мөрт
хүрэхгүй. `Ctrl+Z`‑ээр буцаана.

**Монгол тал бол эх сурвалж.** Хос хэлтэй аль ч талбарын (брэнд, түүх, дүр,
байршил) монгол талыг засахад англи тал нь дагаж шинэчлэгдэнэ — англи тал
түгжигдсэн байсан ч (англид санамсаргүй бичсэн, Camera Director бичсэн).
Гараар зассан англи хувилбар алга болохгүй: **↶ Гараар засснаа сэргээх**
товч гарна. Алхам 5‑ын «Бичиж байхад автоматаар орчуулах» унтраалттай бол
хөндөхгүй.

**Англи орчуулгыг гараар засах — брэндийн бүх мөрөнд.** Орчуулга буруу эсвэл
хэтрүүлэгтэй гарвал (жишээ нь «үлэмж том хүн» → утгагүй англи) мөрийн баруун
(EN) талд шууд засна: гар засвар 🔒 түгжигдэж «ГАРААР ЗАССАН» болж, дахин
орчуулгаар дарагдахгүй. Үүнд 4‑р давхаргын **чиглэлийн 4 мөр** (Харагдац,
Хэмнэл, Эхлээд баталгаажуулах кадр, Эмзэг тал) ч орно — тэд одоо бусад
мөрийн адил хос хэлтэй, засагддаг талбар. Хуучин хадгалалт автоматаар шилжинэ.

🔒 мөрийг юу ч дарж бичихгүй: Авто гүйлт, багц орчуулга, орчуулга явж
байхад англиар бичих — бүгд алгасна. Зөвхөн «Бүгдийг дахин орчуулах»
(баталгаажуулсны дараа) дарна. `→` товч эсвэл монгол талыг засвал түгжээ
тайлагдаж дахин орчуулагдана, хуучин засвар **↶ сэргээх**‑ээр буцна.
Англи талыг бүр арилгавал түгжээ өөрөө тайлагдана.

**Хэтрүүлгээс сэргийлэх дүрэм (`B.REAL_RULE`).** Claude‑д очдог бүх
зохиолтын дуудлагад (брэнд зохиох, чиглэл, Авто → Брэнд, ертөнц, кадрын
жагсаалт) «хүний биеийн хэмжээ, харьцаа, тоо бодит байна; «аврага», «агуу»
мэт үгийг утгаар нь ойлго» гэсэн дүрэм нэмэгдэнэ. Орчуулга ба промт
өнгөлөлтөд мөн «хэмжээ, тоо, харьцааг яг эх бичвэрээр нь үлдээ» гэж заасан.

**Давхардалгүй.** Өнгөлсөн промт брэндийн үгсийг аль хэдийн агуулж болох тул
промт угсрахдаа брэндийн зөвхөн **текстэд байхгүй** хэллэгийг залгана.

**AI туслахууд:** нэг өгүүлбэр нишээс бүтэн брэнд файл зохиох, батлагдсан
гарчгийн форматаар сэдэв санал болгох, юу ч үүсгэхээс өмнө найруулгын
чиглэл гаргуулах. Чиглэл нь монгол (дэлгэцэд) ба англи (промтод) хоёулангаар
нэг дуудлагаар ирж, «Approved direction» болж LAYER 4‑т суух ба туршилтын
кадрын агуулга хоосон бол автоматаар дүүргэнэ. Мөр бүрийг гараар засна.
`✖ Чиглэлийг арилгах` товчоор хасна (`Ctrl+Z`‑ээр буцна).

**Туршилтын кадрын агуулга** нь бусад талбарын адил хос хэлтэй — монголоор
бичихэд өөрөө орчуулагдана. Мөн хамгаалалт бий: аль нэг брэнд талбар
хараахан орчуулагдаагүй байсан ч промт руу монгол текст **хэзээ ч** орохгүй,
офлайн толиор тэр дороо орчуулагдана (`B.toEN`).

**Экспорт:** «Бүтэн 4 давхаргат промт» блокийг хуулж эсвэл `brand-file.txt`
болгон татаад Claude Code, Veo, Higgsfield — аль ч хэрэгсэлд шууд өгнө.

**EN · Англи промт → брэнд (тусдаа хуудас).** Зүүн цэсэнд «Авто»‑гийн
доор. Seedance / Veo‑д бичсэн англи промтоо **наахад** брэнд рүү
автоматаар задарна (дахин задлах бол «🧩 Брэнд рүү задлах»):

| Промт дахь хэсэг | Брэндийн мөр |
|---|---|
| photorealistic, film grain, anamorphic, … mood | 2 · Визуал гарын үсэг |
| backlight, rim light, volumetric light rays | 2 · Гэрэлтүүлэг |
| өнгөний богино хэллэг (Deep black space, Cold blue palette) | 2 · Өнгөний палетт |
| one continuous take, no cuts, lens, tracking | 2 · Камерын дүрэм |
| no text, no people, no explosion … | 2 · Хэзээ ч гаргахгүй («no»‑гүйгээр) |
| no narration, no dialogue, music, sound | 3 · Дуу авианы палетт |
| `0–3s: …` цагийн хуваарь | 4 · Чиглэл · Хэмнэл |
| эхний үйл явдлын өгүүлбэр | 4 · Эхлээд баталгаажуулах кадр + туршилтын кадр |
| `[storyboard] …`, `[@image1] …` мөр | Баталсан кадр (лавлагаа) |

Бүх хэсэг промтоос **үгчлэн** таслагдана — дахин бичихгүй, орчуулахгүй,
Claude шаардахгүй. Бичигдсэн мөр бүр 🔒 («ПРОМТООС ҮГЧЛЭН»), монгол утга нь
хажууд (Claude холбогдсон бол түүгээр, эс бөгөөс толиор ойролцоо).
Промтод байхгүй мөрд (ниш, гарчиг, хоолой…) хүрэхгүй. `Ctrl+Z` нэг алхмаар
буцаана. Промт өөрөө брэндээс тусдаа (төслийн `en`) үгчлэн хадгалагдаж,
📋 хуулах, ⬇ `prompt-en.txt`, ⇄ монгол утга гэсэн товчтой.
`brand.json` нь машинд уншигдах хувилбар — **Camera Director** (`camera.html`)
үүнийг уншиж камерын дүрмийг хоёр талдаа нийцүүлнэ (`CAMERA.md` §2.5).
Ижил домэйн дээр бол Camera Director нээхэд localStorage‑оос **автоматаар**
ачаална; тэндээс дүрэм засаад буцаан бичиж болно. Зүүн талын жагсаалтын
**🎥 Camera Director ↗** товч түүнийг шинэ цонхонд нээнэ (`../camera.html`).
Ганц файлын хувилбарыг `file://` замаар нээсэн ч localStorage хуваалцагддаг
тул гүүр ажиллана.

### 2. Бусад автоматжуулалт
- **Автомат хадгалалт** — хуудсыг хаагаад дахин нээхэд төсөл сэргэнэ (v2‑т алдагддаг байсан).
- **Дүр, байршлыг илрүүлэх** — бичсэн үзэгдлүүдээс шинэ дүр, байршлыг Claude өөрөө олж карт үүсгэнэ.
- **Тууштай байдал** — үзэгдлийн промтод холбогдсон дүр, байршлын дүрслэл автоматаар шингэнэ.
  Ингэснээр олон кадрын дүр төрх тогтвортой болно. (Промт самбараас унтраах боломжтой.)
- **Толины автомат бөглөлт** — таниагүй үгсийг нэг товчоор Claude‑аар орчуулж толинд шингээнэ.
- **Тууштай байдлын шалгалт** — Claude бүх агуулгыг уншиж зөрчлийг жагсаана.
- **Хоосон талбарыг бүгдийг дүүргэх** — бүх дүр, байршлын дутуу талбарыг зэрэг гүйцээнэ.

### 3. Найдвартай ажиллагаа
- Дуудлагын **дараалал** (зэрэг 3), **дахин оролдлого** (429 / түр зуурын алдаанд 4 удаа, хугацаа хоёр дахин),
  **кэш** (ижил текстийг дахин төлбөрлөхгүй), **токен тоолуур**.
- Багц орчуулга: 8 хүртэлх талбарыг нэг JSON дуудлагаар → дуудлагын тоо ~8 дахин бага.
- Алдаа гарвал **офлайн толь руу автоматаар шилжинэ** — ажил зогсохгүй.
- Буцаах/дахин хийх (Ctrl+Z / Ctrl+Shift+Z), төслийн сан, JSON / Markdown / CSV / TXT экспорт.
- **Загвар:** анхдагч нь Opus 5.5 (хамгийн чадвартай). «Claude холболт»
  цонхноос Sonnet 5 / Sonnet 4.6 / Haiku 4.5 сонгож болно — хямд, хурдан.
  Сонголт хөтчид хадгалагдах ба серверийн прокси түүнийг дарж бичихгүй.
  Авто гүйлт брэндийн бэлэн мөрүүдийг дахин орчуулж зардал гаргахгүй.

### 4. Толь — 10,766 үг, 154 ангилал
Ангилал бүрээр шүүж хайна. Морфологи (дагавар тайлах, эгшиг сэргээх, тийн ялгал)
нь толины хэмжээг бодит хэрэглээнд хэдэн дахин өргөжүүлнэ.

**v3.1 өргөтгөл (+727 үг, `d47`–`d54`).** Үгийн тоо биш, **хамрах хүрээ**‑г
хэмжиж нэмсэн: бодит текстийг офлайн хөдөлгүүрээр гүйлгэж таниагүй үгсийг
тоолоод, цоорхойг нь нөхсөн.

| Файл | Агуулга |
|---|---|
| `d47` | Брэнд · хальс, зохиомж, гэрэл, өнгө засвар |
| `d48` | Үндэсний хувцас · дээлийн хэсэг, гоёл, угсаатны хэв маяг |
| `d49` | Хөгжим · продакшн, микс, монгол зэмсэг |
| `d50` | YouTube, контент бүтээх |
| `d51` | Үзэгдлийн үйл үг, дайвар үг |
| `d52`–`d54` | **Цөм** — түгээмэл үйл үг, туслах үг, өдөр тутмын нэр үг |

Шалгалтаар толинд **түгээмэл үйл үгсийн дөнгөж 46%** нь байсныг илрүүлсэн тул
цөмийн үгс хамгийн их өгөөж өгсөн. Толь нэмэхийн **өмнө** хараагүй текст дээр
хамрах хүрээ **85.9% → 94.6%** болж, таниагүй үг 62%‑иар буурсан.

Мөн засагдсан:
- Буруу утгатай 6 үг: *хормой* → hem, *хөдлөх* → moving, *гулсах* → sliding,
  *хийсэх* → fluttering, *гэзэг* → braid, *хатан* → queen.
- Морфологи: `‑ины/‑ьд` («морины», «хонины», «морьд»), далд «н»‑тэй өгөх
  орших («нүүрэнд»), материалын тэмдэг нэр («цасан», «модон»), `байна`
  туслах үйл үгийг хасах.
- `шиг` / `мэт` → «like X» (англи дараалал), `35мм` → 35mm, `1-р` → 1st, `8с` → 8s.

Хаалттай бичигдсэн 81 түлхүүр (жишээ нь «хөдөлгөөн (камерын)») текстэд
хэзээ ч таардаггүйг анхаарна уу — шинэ үг нэмэхдээ хаалт бүү хэрэглэ.

Шалгах:
```bash
node tools/check-dict.mjs       # ангилал, тоо, давхардал, латин үсэг
node tools/check-translate.mjs  # офлайн орчуулгын регресс тест (27 тохиолдол)
```
Толь эсвэл морфологи засах бүрдээ **хоёуланг** ажиллуулна. Орчуулгын тест
нь өмнө ажиллаж байсан орчуулга эвдэрсэн эсэхийг барина — жишээ нь дагавар
нэмэхэд «харан» (харж) нь «хар» (black) болж таарах гэх мэт.

## Байршуулалт

### Vercel (санал болгож буй)
Репог Vercel‑д холбоход л хангалттай — тохиргоо шаардахгүй.

- Апп: `https://<төсөл>.vercel.app/world-builder/`
- Прокси: `/api/claude` (`api/claude.js`)

**Түлхүүргүй ажиллуулах:** Vercel төслийн *Settings → Environment Variables* дотор
`ANTHROPIC_API_KEY` нэмнэ. Ингэвэл зочид түлхүүр оруулах шаардлагагүй —
сервер өөрөө Anthropic руу залгана. Нэмэлт хувьсагчид:

| Хувьсагч | Утга |
|---|---|
| `ANTHROPIC_API_KEY` | заавал — үүнгүй бол прокси 501 буцааж, апп хэрэглэгчийн түлхүүр рүү шилжинэ |
| `WB_MODEL` | анхдагч загвар (`claude-opus-5-5`). Хэрэглэгч «Claude холболт» цонхноос өөрөө сонгосон бол түүнийх нь давамгайлна |
| `WB_MAX_TOKENS` | нэг хүсэлтийн дээд хязгаар (8000) |
| `WB_RATE_MAX` | нэг IP‑ээс минутад зөвшөөрөх дуудлага (40) |

Прокси нэг хүсэлтийн биеийг 4 MB (Vercel‑ийн хязгаар 4.5 MB), зургийн тоог 4
хүртэл хязгаарладаг — зураг бүр эзэмшигчийн түлхүүрээр төлөгдөнө.

### Ганц файлаар (интернэтгүй)
```bash
node tools/build-single.mjs
```
→ `world-builder/ertunts-buteegch.html` (~710 KB). Давхар товшиход нээгдэнэ.
Прокси байхгүй тул AI хэрэглэхийн тулд ⚙ товчоор API түлхүүрээ оруулна;
түлхүүргүй үед 10 мянган үгтэй офлайн толиор ажиллана.

## Аюулгүй байдал
API түлхүүр төслийн JSON файлд **хэзээ ч** ороогүй. «Сана» гэснийг сонгосон
үед л хөтчийн localStorage‑д хадгалагдана, эс бөгөөс зөвхөн санах ойд байна.

огт өгөхгүй байх.
