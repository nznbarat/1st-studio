# Ертөнц Бүтээгч v3

Монголоор бичээд англи AI промт автоматаар гаргадаг кино бүтээх өрөө.
v2‑оос ялгаатай нь **автоматжуулалт** ба **10 мянган үгтэй ангилсан толь**.

---

## Юу шинэ болов

### 1. Автомат горим (Алхам 0)
Нэг санаа бичээд **⚡ Ертөнц бүтээх** дарахад Claude дараах бүх ажлыг дараалан хийнэ:

| Алхам | Юу болох |
|---|---|
| Ертөнц зохиох | логлайн, N үзэгдэл, N дүр, N байршил — бүгд монголоор |
| Автомат холбох | үзэгдэл бүрийг дүр, байршилтай нь нэрээр нь холбоно |
| Орчуулга | бүх талбарыг англи руу — **олон талбарыг нэг API дуудлагаар** |
| Кадрын задаргаа | үзэгдэл бүрийг 2–8 кадарт хувааж, камерын заавар өгнө |
| Промт өнгөлөлт | сонгосон хэрэгсэлд (Midjourney / Kling / Higgsfield / Sora) тааруулж дахин бичнэ |

Явцын мөр, алхам бүрийн бүртгэл, **■ Зогсоох** товч бий.

### 1.5. Брэнд файл — сувгийн гарын үсэг (Алхам 1)

AI таны бодлыг уншиж чаддаггүй. Заагаад өгөхгүй бол хамгийн **ердийн**
хувилбар руу ордог — ердийн зүйл нь түүний хувьд хамгийн аюулгүй таамаг.
Тиймээс сувгийн харагдац, хоолойг нэг удаа бичээд бүх ангид дахин ашиглана.

**Гурван зарчим:**

| Зарчим | Юу хийдэг |
|---|---|
| **Нэг фрэйм дүрэм** | Бүтэн видео үүсгэхээсээ өмнө **ганц зураг** гаргаж стилээ шалгана. Зураг засах нь видео засахаас олон дахин хямд. Таалагдвал «Стиль тогтоосон» гэж **түгжинэ** |
| **Брэнд файл** | Харагдац, гэрэл, палетт, камерын дүрэм, хоолойны өнгө аяс, дуу авианы палетт — нэг дор. Промт болгонд автоматаар шингэнэ |
| **4 давхаргат бүтэц** | Судалгаа → Харагдац → Хоолой → Хяналт. Аль нэг нь дутвал AI өөрөө нөхнө — ердийн зүйлээр |

**Дөрвөн давхарга:**

| # | Давхарга | Агуулга |
|---|---|---|
| 1 | **Судалгаа** | Сувгийн ниш, батлагдсан гарчгийн формат (**хос хэлтэй** — мастер промтод англиар орно), сэдвийн жагсаалт |
| 2 | **Харагдац** | Визуал гарын үсэг, гэрэлтүүлэг, өнгөний палетт, камерын дүрэм, «хэзээ ч гаргахгүй» |
| 3 | **Хоолой** | Өгүүлэгчийн өнгө аяс, хэрэглэдэг/хэрэглэдэггүй үг, дуу авианы палетт |
| 4 | **Хяналт** | «Юу ч үүсгэхээс өмнө чиглэлээ харуул» + AI‑ийн санал болгосон чиглэл — хоёулаа мастер промтын LAYER 4‑т орно |

**Хаана нөлөөлдөг вэ:**

- 2‑р давхарга (харагдац) нь `PR.decorate` дундуур **бүх промтод** нэмэгдэнэ.
  Алхам 5‑ын «Брэнд файлыг бүх промтод шингээх» тэмдэглэгээгээр унтраана.
- «Хэзээ ч гаргахгүй» талбар нь **сөрөг промтод** автоматаар нийлнэ.
- Брэнд контекст нь **Авто горимд** монгол текст зохиох үед AI‑д өгөгдөж,
  промт өнгөлөх үед стилээс гажихаас сэргийлнэ.
- Стиль түгжигдээгүй байхад «⚡ Ертөнц бүтээх» дарвал нэг удаагийн сануулга гарна
  (брэнд файл огт хоосон бол сануулахгүй).

**AI туслахууд:** нэг өгүүлбэр нишээс бүтэн брэнд файл зохиох, батлагдсан
гарчгийн форматаар сэдэв санал болгох, юу ч үүсгэхээс өмнө найруулгын
чиглэл гаргуулах. Чиглэл нь монгол (дэлгэцэд) ба англи (промтод) хоёулангаар
нэг дуудлагаар ирж, «Approved direction» болж LAYER 4‑т суух ба туршилтын
кадрын агуулгыг автоматаар дүүргэнэ. `✖ Чиглэлийг арилгах` товчоор хасна.

**Туршилтын кадрын агуулга** нь бусад талбарын адил хос хэлтэй — монголоор
бичихэд өөрөө орчуулагдана. Мөн хамгаалалт бий: аль нэг брэнд талбар
хараахан орчуулагдаагүй байсан ч промт руу монгол текст **хэзээ ч** орохгүй,
офлайн толиор тэр дороо орчуулагдана (`B.toEN`).

**Экспорт:** «Бүтэн 4 давхаргат промт» блокийг хуулж эсвэл `brand-file.txt`
болгон татаад Claude Code, Veo, Higgsfield — аль ч хэрэгсэлд шууд өгнө.
`brand.json` нь машинд уншигдах хувилбар — **Camera Director** (`camera.html`)
үүнийг уншиж камерын дүрмийг хоёр талдаа нийцүүлнэ (`CAMERA.md` §2.5).
Ижил домэйн дээр бол Camera Director нээхэд localStorage‑оос **автоматаар**
ачаална; тэндээс дүрэм засаад буцаан бичиж болно. Зүүн талын жагсаалтын
**🎥 Camera Director ↗** товч түүнийг шинэ цонхонд нээнэ (`../camera.html`).
Ганц файлын хувилбарыг `file://` замаар нээсэн ч localStorage хуваалцагддаг
тул гүүр ажиллана.

### 2. Бусад автоматжуулалт
- **Автомат хадгалалт** — хуудсыг хаагаад дахин нээхэд төсөл сэргэнэ (v2‑т алдагддаг байсан).
- **Дүр, байршлыг илрүүлэх** — бичсэн үзэгдлүүдээс шинэ дүр, байршлыг Claude өөрөө олж карт үүсгэнэ.
- **Тууштай байдал** — үзэгдлийн промтод холбогдсон дүр, байршлын дүрслэл автоматаар шингэнэ.
  Ингэснээр олон кадрын дүр төрх тогтвортой болно. (Промт самбараас унтраах боломжтой.)
- **Толины автомат бөглөлт** — таниагүй үгсийг нэг товчоор Claude‑аар орчуулж толинд шингээнэ.
- **Тууштай байдлын шалгалт** — Claude бүх агуулгыг уншиж зөрчлийг жагсаана.
- **Хоосон талбарыг бүгдийг дүүргэх** — бүх дүр, байршлын дутуу талбарыг зэрэг гүйцээнэ.

### 3. Найдвартай ажиллагаа
- Дуудлагын **дараалал** (зэрэг 3), **дахин оролдлого** (429 / түр зуурын алдаанд 4 удаа, хугацаа хоёр дахин),
  **кэш** (ижил текстийг дахин төлбөрлөхгүй), **токен тоолуур**.
- Багц орчуулга: 8 хүртэлх талбарыг нэг JSON дуудлагаар → дуудлагын тоо ~8 дахин бага.
- Алдаа гарвал **офлайн толь руу автоматаар шилжинэ** — ажил зогсохгүй.
- Буцаах/дахин хийх (Ctrl+Z / Ctrl+Shift+Z), төслийн сан, JSON / Markdown / CSV / TXT экспорт.

### 4. Толь — 10,763 үг, 154 ангилал
Ангилал бүрээр шүүж хайна. Морфологи (дагавар тайлах, эгшиг сэргээх, тийн ялгал)
нь толины хэмжээг бодит хэрэглээнд хэдэн дахин өргөжүүлнэ.

**v3.1 өргөтгөл (+727 үг, `d47`–`d54`).** Үгийн тоо биш, **хамрах хүрээ**‑г
хэмжиж нэмсэн: бодит текстийг офлайн хөдөлгүүрээр гүйлгэж таниагүй үгсийг
тоолоод, цоорхойг нь нөхсөн.

| Файл | Агуулга |
|---|---|
| `d47` | Брэнд · хальс, зохиомж, гэрэл, өнгө засвар |
| `d48` | Үндэсний хувцас · дээлийн хэсэг, гоёл, угсаатны хэв маяг |
| `d49` | Хөгжим · продакшн, микс, монгол зэмсэг |
| `d50` | YouTube, контент бүтээх |
| `d51` | Үзэгдлийн үйл үг, дайвар үг |
| `d52`–`d54` | **Цөм** — түгээмэл үйл үг, туслах үг, өдөр тутмын нэр үг |

Шалгалтаар толинд **түгээмэл үйл үгсийн дөнгөж 46%** нь байсныг илрүүлсэн тул
цөмийн үгс хамгийн их өгөөж өгсөн. Толь нэмэхийн **өмнө** хараагүй текст дээр
хамрах хүрээ **85.9% → 94.6%** болж, таниагүй үг 62%‑иар буурсан.

Мөн засагдсан:
- Буруу утгатай 6 үг: *хормой* → hem, *хөдлөх* → moving, *гулсах* → sliding,
  *хийсэх* → fluttering, *гэзэг* → braid, *хатан* → queen.
- Морфологи: `‑ины/‑ьд` («морины», «хонины», «морьд»), далд «н»‑тэй өгөх
  орших («нүүрэнд»), материалын тэмдэг нэр («цасан», «модон»), `байна`
  туслах үйл үгийг хасах.
- `шиг` / `мэт` → «like X» (англи дараалал), `35мм` → 35mm, `1-р` → 1st, `8с` → 8s.

Хаалттай бичигдсэн 81 түлхүүр (жишээ нь «хөдөлгөөн (камерын)») текстэд
хэзээ ч таардаггүйг анхаарна уу — шинэ үг нэмэхдээ хаалт бүү хэрэглэ.

Шалгах:
```bash
node tools/check-dict.mjs       # ангилал, тоо, давхардал, латин үсэг
node tools/check-translate.mjs  # офлайн орчуулгын регресс тест (26 тохиолдол)
```
Толь эсвэл морфологи засах бүрдээ **хоёуланг** ажиллуулна. Орчуулгын тест
нь өмнө ажиллаж байсан орчуулга эвдэрсэн эсэхийг барина — жишээ нь дагавар
нэмэхэд «харан» (харж) нь «хар» (black) болж таарах гэх мэт.

## Байршуулалт

### Vercel (санал болгож буй)
Репог Vercel‑д холбоход л хангалттай — тохиргоо шаардахгүй.

- Апп: `https://<төсөл>.vercel.app/world-builder/`
- Прокси: `/api/claude` (`api/claude.js`)

**Түлхүүргүй ажиллуулах:** Vercel төслийн *Settings → Environment Variables* дотор
`ANTHROPIC_API_KEY` нэмнэ. Ингэвэл зочид түлхүүр оруулах шаардлагагүй —
сервер өөрөө Anthropic руу залгана. Нэмэлт хувьсагчид:

| Хувьсагч | Утга |
|---|---|
| `ANTHROPIC_API_KEY` | заавал — үүнгүй бол прокси 501 буцааж, апп хэрэглэгчийн түлхүүр рүү шилжинэ |
| `WB_MODEL` | анхдагч загвар (`claude-sonnet-4-6`) |
| `WB_MAX_TOKENS` | нэг хүсэлтийн дээд хязгаар (8000) |
| `WB_RATE_MAX` | нэг IP‑ээс минутад зөвшөөрөх дуудлага (40) |

### Ганц файлаар (интернэтгүй)
```bash
node tools/build-single.mjs
```
→ `world-builder/ertunts-buteegch.html` (~671 KB). Давхар товшиход нээгдэнэ.
Прокси байхгүй тул AI хэрэглэхийн тулд ⚙ товчоор API түлхүүрээ оруулна;
түлхүүргүй үед 10 мянган үгтэй офлайн толиор ажиллана.

## Файлын бүтэц

```
world-builder/
  index.html            модуль ачаалдаг үндсэн хуудас
  css/app.css
  js/00-core.js         нэрийн орон зай, хадгалалт, мэдэгдэл
  js/10-grammar.js      монгол морфологи, тийн ялгал → англи
  js/20-dict.js         толины бүртгэл, хайлт
  js/dict/d01…d54.js    ангилсан үгсийн сан (154 ангилал)
  js/30-api.js          Claude клиент: прокси → түлхүүр → офлайн
  js/40-translate.js    офлайн хөдөлгүүр + багц AI орчуулга
  js/50-state.js        төлөв, автомат хадгалалт, undo, төслийн сан
  js/52-brand.js        брэнд файл, нэг фрэйм дүрэм, 4 давхаргат мастер промт
  js/55-prompt.js       промт угсрагч, экспорт
  js/60-ui.js           дэлгэцийн бүрэлдэхүүн
  js/70-auto.js         автомат гүйлт (pipeline)
  js/75-demo.js         жишээ төсөл
  js/80-main.js         холболт, эхлүүлэлт
api/claude.js           Vercel serverless прокси
tools/check-dict.mjs    толины шалгалт
tools/build-single.mjs  ганц файл угсрагч
```

Толь засах бол `js/dict/*.js` дотор `WB.dict.add({ id, label, icon, w:{…} })`
дуудлага нэмнэ — бусад код өөрчлөх шаардлагагүй. Дараа нь `check-dict` ажиллуулж
давхардал байхгүй эсэхийг шалгаад `build-single` дахин гүйлгэнэ.

## Аюулгүй байдал
API түлхүүр төслийн JSON файлд **хэзээ ч** ороогүй. «Сана» гэснийг сонгосон
үед л хөтчийн localStorage‑д хадгалагдана, эс бөгөөс зөвхөн санах ойд байна.
Хамгийн найдвартай нь — Vercel орчны хувьсагч ашиглаж, түлхүүрийг хөтөч рүү
огт өгөхгүй байх.
