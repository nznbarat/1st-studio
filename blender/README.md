# Blender тайзнууд

Blender дотор ажиллуулахад бүтэн тайз (set) үүсгэдэг процедурал скриптүүд.
Гараар загварчлахгүй — код нь геометр, материал, гэрэл, камерыг бүгдийг үүсгэнэ.
Тоонуудыг өөрчлөөд дахин ажиллуулахад тайз шинэчлэгдэнэ.

## cockpit.py — сансрын хөлгийн кабин

Хоёр том налуу цонх, дунд нь багана, урдаа бүлээн гэрэлтэй урт консол,
өндөр түшлэгтэй нисгэгчийн суудал, дээвэрт хоолой ба унжсан кабель,
шалны метал хавтангууд. Цонхны цаана од ба сул мананцар.

### Ашиглах

Blender дотор:

```
Scripting таб → Open → blender/cockpit.py → Run Script (Alt+P)
```

Командын мөрнөөс рендер хүртэл:

```
blender -b -P blender/cockpit.py -- --render shot.png --res 1920x1080 --samples 128
blender -b -P blender/cockpit.py -- --render shot.png --angle seat
```

**Blender 5.2.2 LTS** дээр ажиллана (5.0.1 дээр ч шалгагдсан).

`blender` команд байхгүй бол (жишээ нь cloud орчинд) `blender/run.sh`
ашиглана — bpy 5.2.2-ийг Python 3.13-тай хамт өөрөө суулгаад ажиллуулна:

```
blender/run.sh blender/cockpit.py -- --render shot.png
```

### Юу үүсэх вэ

| Хэсэг | Тайлбар |
|---|---|
| **Гүүр (кабин)** | 2 том цонх шалнаас тааз хүртэл, дунд нь ганц багана, урт консол, суудал, таазны гэрэл |
| **0110 хөлөг** | ~265м урт ачааны хөлөг: хамрын шаантаг, ачааны 6 сегмент X тулаастай, хойд блок, 4 хөдөлгүүр |
| **Гэрэл** | Алслагдсан од (нар) хойноос, доторх бүлээн гэрэл, доод талын улаан зурвас, гэрэлтэй жижиг цонхнууд |
| **Нислэг** | 155 фреймийн камерын зам: гаднаас → цонхоор нэвтэрч → доторх орчны өргөн кадр |

### Сонголтууд

| Сонголт | Утга |
|---|---|
| `--render FILE` | рендерлэж хадгална (энэ сонголтгүй бол зөвхөн тайзыг барина) |
| `--format NAME` | гаралтын хэлбэр: `png` (үндсэн), `png16`, `exr`, `exr32`. Resolve-д **`exr`** |
| `--res 1920x1080` | нягтрал |
| `--samples 128` | Cycles-ийн дээж. Урьдчилсан харахад 32–48, эцсийнд 128+ |
| `--angle NAME` | камерын өнцөг: `wide`, `seat`, `window`, `corner`, `bow`, `ship`, `stern`, `pilot`, `console`, `vista` |
| `--frame N` | анимацийн тодорхой фрейм рүү очно |
| `--anim` | `--render`-тэй хамт — бүх фреймийн дараалал рендерлэнэ |
| `--device gpu` | `AUTO` (үндсэн) нь GPU байвал өөрөө олно. `cpu` гэж тулгаж болно |
| `--save-blend FILE` | тайзыг `.blend` болгон хадгална. Камерын нум, түгшүүр, товчлуурын анимац бүгд дотор нь орно — нээгээд шууд Space дарахад тоглоно |
| `--no-seat` | сандлыг нуана — жүжигчин өөрийн сандал дээр сууж байвал |
| `--pass bg\|fg` | тайзыг гүнээр хоёр давхарга болгож хуваана (доорх Resolve хэсгийг үз) |
| `--split М` | хуваалтын зайг ТОГТМОЛ болгоно. Үүнгүй бол камертай хамт хөдөлнө |
| `--arc N` | N фреймийн турш камер нум зурна |
| `--arc-hold 0.5` | нумын эхний хэдэн хувьд камер хөдөлгөөнгүй зогсохыг тогтооно |
| `--arc-settle 0.90` | нумын хөдөлгөөн хэдэн хувьд дуусахыг тогтооно. 0.90 = фрейм 562 (23.4 с). Доорх хэмжилтийг үз |
| `--slide М` | камерыг харцандаа перпендикуляр М метр гулсуулна |
| `--slide-frames N` | гулсалтын урт |
| `--alert 0.5` | мөргөлдөөний түгшүүрийн гэрэл хэдэн хувиас асахыг тогтооно |
| `--press 0.55` | хажуугийн консолын товчлуур хэдэн хувиас дарагдахыг тогтооно. 0.55 = 343-р фрейм — зүүн гар жолооноос салж консолд хүрэх мөч (~14 с) |
| `--cover` | гарыг далдлах товгор хэсгийг нэмнэ |
| `--cine` | киноны төрх: 180° хөдөлгөөний бүдгэрэлт + гүний талбар (фокус нь гар дээр) |
| `--shotlist` | дүр солигдох дарааллыг хэвлэнэ (тайз барихгүй) |
| `--shot NAME` | тухайн дүрийг сонгоно: нэрээр (`drift`) эсвэл дугаараар (`1`) |
| `--meteor` | солир ба цохилтын хэлтэрхийг асаана (үндсэндээ унтраалттай) |
| `--aov` | `--render`-тэй хамт — Emission ба гэрлийн бүлгүүдийг тусдаа EXR дараалал болгоно (доор) |
| `--frames A-B` | зөвхөн энэ хүрээг рендерлэнэ — туршилт, эсвэл тасарсан рендерийг үргэлжлүүлэх |
| `--fstop 2.0` | `--cine`-тэй хамт — линзний нүх. Жижиг тоо = илүү бүдгэрсэн ар тал |

### Тохируулах

Файлын эхэнд байгаа `CFG` толь бүх хэмжээг барина:

| Түлхүүр | Юу хийдэг |
|---|---|
| `room` | өрөөний өргөн (X), гүн (Y), өндөр (Z), метрээр |
| `window` | цонхны налуу өнцөг, доод/дээд ирмэг, баганын өргөн, хуваагчийн тоо |
| `console` | консолын байрлал, өргөн, гүн, өндөр, дээд гадаргуугийн налуу, гэрэлтэх хавтангийн тоо |
| `seat` | суудлын байрлал ба хэмжээ |
| `grime` | 0 = цэвэр шинэ метал, 1 = маш бохир, зэвэрхэг |
| `haze` | агаарын манангийн нягт. 0 бол унтарна (рендер эрс хурдасна) |
| `exposure` | ерөнхий гэрэлтэлт. Бараан болгох бол сөрөг тоо |
| `warm` / `cool` | консолын бүлээн ба цонхны хүйтэн гэрлийн өнгө |
| `seed` | санамсаргүй байдлын үр. Өөрчилбөл товч, хавтангийн байрлал шинэчлэгдэнэ |
| `clear_scene` | Blender-ийн анхны Cube/Light/Camera-г устгах эсэх |
| `ship` | хөлгийн их бие: дугаар, өргөн, зузаан, хамрын урт, сегментийн тоо, хөдөлгүүрийн радиус |
| `sun` | алслагдсан одны хүч ба өнгө |
| `flythrough` | цонхоор нэвтэрдэг камерын анимац үүсгэх эсэх |
| `device` | `AUTO` / `GPU` / `CPU`. AUTO нь OptiX, CUDA, HIP, Metal, oneAPI-г дарааллаар шалгана |

Тайз бүхэлдээ `COCKPIT` коллекцид үүснэ. Дахин ажиллуулах бүрд тэр коллекц
цэвэрлэгдэж шинээр баригдана — тайзны гадна байгаа юманд хүрэхгүй.

### Камерын хөдөлгөөнийг бичлэгтэй тулгасан хэмжилт

Бичлэгээс 6 фрейм тутам (105 цэг) хоёр зүйлийг хэмжиж CG-тэй тулгасан:
**толгойн орой** ба **баруун нударга**. Үр дүн:

| Хугацаа | Юу хэмжсэн | Таарц |
|---|---|---|
| 0–13 с | жолооны бариул ↔ нударга (51 цэг) | **RMS 3.4%**, хазайлт +0.015 |
| 13–26 с | толгойн орой, `--arc-settle 0.70` | RMS 7.7% |
| 13–26 с | толгойн орой, `--arc-settle 0.90` | **RMS 5.2%** |

**Эхний 13 секунд бат.** Камер тэнд хөдөлдөггүй нь баталгаажсан: толгойн
оройн x нь 0.48 ± 0.02 дотор тогтвортой.

**Сүүлийн 13 секундэд** `settle`-ийг 0.62-оос 1.01 хүртэл сканнердахад
хамгийн бага алдаа 0.89–0.92 дээр гарсан. Өмнөх 0.70 нь камерыг 18.2 с-д
зогсоож байсан бол бичлэг ~24 с хүртэл өөрчлөгдсөөр байна.

**Шийдэгдэхгүй зөрчил.** Нударга нь камерыг 17.5 с гэхэд зогссон байхыг
"хүсдэг" (тэр үед гар нь кадрын баруун ирмэгт хүрч 0.996-д тултал явдаг),
харин толгой нь 24 с хүртэл хөдөлсөөр байхыг хүсдэг. Нэг хөшүүн камерын
хөдөлгөөнөөр хоёуланг нь хангах боломжгүй — учир нь жүжигчин өөрөө биеэ
хөдөлгөж байгаа. Ногоон бүрхүүл дээр тэмдэг байхгүй тул үүнээс цааш
нарийвчлах арга байхгүй (фазын корреляци итгэл 0.03–0.2, NCC 0.46 —
хоёулаа бүтсэнгүй).

Тиймээс `--arc-settle`-ийг туг болгон үлдээв: 0.70 ба 0.90 хоёрыг богино
рендерээр туршаад нүдээрээ сонго.

### Дүр солигдох дараалал

26 секундыг 3 секунд тутам солигдох 9 дүр болгож хуваасан. Жагсаалтыг
`--shotlist`-ээр харна.

**Гол хязгаарлалт:** ногоон дэвсгэрийн бичлэг нэг тогтмол камераас
авагдсан тул кабины бүх дүр (`int`) нэг өнцөгтэй байх ёстой. Зөвхөн гадна
дүрүүд (`ext`) өнцгөө сольдог. Камерын 624 фреймийн нум тасралтгүй
үргэлжилнэ — бид зүгээр л түүнээс хэсэг хэсгийг таслан авч байна, тиймээс
кабин руу буцаж ирэх бүрд хөдөлгөөн нь үргэлжилсэн хэвээр байна.

```bash
# гадна дүр — цэвэр CG, эвлүүлэх шаардлагагүй
blender -b -P blender/cockpit.py -- --angle pilot --no-seat --arc 624 \
        --alert 0.5 --press 0.55 --cine --shot drift \
        --format exr --render out/drift/f --anim --res 1920x1080 --samples 96

# кабины дүр — bg/fg хоёр давхаргаар, бичлэгтэй эвлүүлнэ
blender -b -P blender/cockpit.py -- --angle pilot --no-seat --arc 624 \
        --alert 0.5 --press 0.55 --cine --shot calm --pass bg \
        --format exr --render out/calm-bg/f --anim --res 1920x1080 --samples 96
```

Дарааллыг өөрчлөх бол `SHOTS` жагсаалтын мөрүүдийг солино. Солирыг
`--meteor`-оор асаавал `meteor_in` / `impact` / `debris` өнцгүүд бэлэн байна.

### Аль нь Blender-т, аль нь Resolve-д

Дүрэм: **3D мэдээллээс хамаардаг бүхэн Blender-т, эцсийн зургийн 2D
боловсруулалт Resolve-д.** Дараалал нь албадмал — 624 фрейм рендерлэсний
дараа Blender рүү буцах нь маш үнэтэй.

| Blender-т (`--cine`) | Resolve-д |
|---|---|
| Хөдөлгөөний бүдгэрэлт — тайзны хөдөлгөөний вектор шаардана | Өнгө засвар, LUT |
| Гүний талбар — бодит гүн шаардана | Film grain (ширхэг) |
| Волюметрийн манан, гэрлийн багана | Halation, bloom, vignette |
| Дээж (samples) — чимээгүй зураг | Линзний гажилт, chromatic aberration |

Фокус нь `CAM_AIM` дээр буюу гар дээр тогтдог бөгөөд нумын анимацид хамт
хөдөлдөг. **Фокус рендерт шингэнэ** — дараа нь өөрчлөхийн тулд `--fstop`-оо
сольж дахин рендерлэх хэрэгтэй, тиймээс эцсийн 624 фреймийг эхлүүлэхийн
өмнө нэг фрейм дээр туршиж шийд.

### DaVinci Resolve Studio-д эвлүүлэх

Хоёр давхаргыг тусад нь рендерлэнэ. `fg` нь жүжигчнээс **ойр** бүх зүйл
(ил тод дэвсгэртэй), `bg` нь **хол** бүх зүйл. Хуваалт нь эд ангиар биш,
камераас суудал хүртэлх зайгаар явагддаг тул ямар ч өнцөгт зөв ажиллана.

Камер хөдөлдөг тул энэ зай фрейм бүрт өөр байна (нумын турш 1.94м-ээс
1.39м хүртэл). Тиймээс хуваалт нь тогтмол биш — камертай хамт
түлхүүрлэгдэж хөдөлнө. Тогтмол байлгавал камер ойртох үед жүжигчний **ард**
байгаа эд ангиуд урд давхаргад орж биеийг нь халхална.

```bash
# ард — сансар, цонх, хөлгийн их бие
blender -b -P blender/cockpit.py -- --angle pilot --no-seat \
        --arc 624 --alert 0.5 --press 0.55 \
        --pass bg --format exr --render out/bg/f --anim \
        --res 1920x1080 --samples 96

# урд — консолын ирмэг, жолоо, хажуугийн самбар
blender -b -P blender/cockpit.py -- --angle pilot --no-seat \
        --arc 624 --alert 0.5 --press 0.55 \
        --pass fg --format exr --render out/fg/f --anim \
        --res 1920x1080 --samples 96
```

**1. Өнгөний удирдлага (эхлээд үүнийг хий).**
Project Settings → Color Management → Color science: **DaVinci YRGB Color
Managed**, Output color space: **Rec.709 Gamma 2.4**.

**2. Оруулах өнгөний орон зайг клип бүрт зааж өг.** Media Pool дотор клип
дээр баруун товч → Clip Attributes:

| Клип | Input Color Space |
|---|---|
| `bg/f####.exr`, `fg/f####.exr` | Rec.709 / **Linear** |
| ногоон дэвсгэрийн бичлэг (HLG) | **Rec.2100 HLG** |

EXR нь Blender-ийн AgX-гүй, шугаман өгөгдөл хадгалдаг — бүх өнгө засвар
Resolve дээр хийгдэнэ. HLG-г зөв зааж өгөхгүй бол бичлэг цайрч, өнгө нь
хэт ханасан харагдана; энэ бол CapCut дээр гардаг байсан асуудал.

**3. Timeline — гурван зам:**

| Зам | Агуулга |
|---|---|
| V3 | `fg` дараалал — консолын ирмэг, жолоо (жүжигчний **урд**) |
| V2 | ногоон дэвсгэрийн бичлэг |
| V1 | `bg` дараалал — сансар, цонх (жүжигчний **ард**) |

**4. Ногоон дэвсгэрийг салгах.** V2 клипийг Fusion page дээр нээж
`MediaIn → DeltaKeyer → MediaOut`. Delta Keyer-ийн Background Color-оор
ногоон өнгийг сонгоод Matte таб дотор Clean Black / Clean White-аар
цэвэрлэнэ; despill нь өөрийнх нь Spill таб дотор байдаг. Color page дээр
хийх бол node graph дотор баруун товч → **Add Alpha Output**, дараа нь
Qualifier-ийн 3D Keyer.

**5. Нягтрал.** Ногоон бичлэг 854×480 бол 1920×1080 timeline дээр 2.25
дахин томроно. Эх файлаа бүтэн нягтралаар дахин экспортлох нь хамгийн зөв.
Боломжгүй бол Clip Attributes → **Super Scale → 2x Enhanced** (зөвхөн
Studio-д байдаг) нь энгийн томруулалтаас мэдэгдэхүйц дээр.

**6. Alpha.** `fg` EXR-ийн alpha нь premultiplied. Clip Attributes → Alpha
Mode → **Premultiplied** гэж тааруулбал ирмэг дээр хар хүрээ гарахгүй.

**7. CG-г бичлэгтэй нийлүүлэх.** Color page дээр `fg`/`bg` давхаргад
бичлэгийн үр тарианы хэмжээгээр Film Grain OFX нэмж, бага зэрэг Blur
(0.3–0.5) тавибал хоёр эх үүсвэр нэг камераас гарсан мэт болно.

**8. Гаргах.** Deliver page → H.265, Rec.709 Gamma 2.4, 24fps.

### Нэмэлт давхаргууд (`--aov`) — Resolve дээр гэрлийг тусад нь тохируулах

`--aov` өгвөл үндсэн `f####.exr`-ийн хажууд `aov/` хавтас үүсч гурван
дараалал бичигдэнэ. Бүгд Combined-тэй ижил alpha-тай, шугаман, 16 бит:

| Дараалал | Юу агуулдаг | Resolve дээр юу хийх боломж |
|---|---|---|
| `aov/emit####.exr` | Гэрэлтдэг гадаргуу: дэлгэц, товчлуур, гэрлийн зурвас | Консолын гэрлийн хүч, өнгийг дахин рендергүй өөрчлөх |
| `aov/alert####.exr` | Улаан түгшүүрийн 4 гэрлийн хувь нэмэр | Анивчлагын хүчийг сулруулах, хүчтэй болгох, бүр унтраах |
| `aov/key####.exr` | Консолын бүлээн үндсэн гэрлүүд (WarmSpill, DeskFill, CeilFill) | Бичлэгийн нүүрний гэрэлтэй дулаан, хүчийг нь тааруулах |

**Хэрхэн ашиглах.** Combined нь эдгээрийг аль хэдийн агуулдаг. Тиймээс
pass-ыг Combined дээр **Add** горимоор давхарлаж, gain-ийг `k − 1`
болгоно — `k` нь хүссэн үржүүлэгч:

- alert-ийг хоёр дахин хүчтэй → alert замын gain = **+1.0**
- alert-ийг хагас болгох → gain = **−0.5** (Add горимд сөрөг gain хасна)
- alert-ийг бүр унтраах → gain = **−1.0**

Замын дараалал: `bg` → `bg-ийн aov` (Add) → бичлэг → `fg` → `fg-ийн aov` (Add).
Давхарга бүрийн aov нь тухайн давхаргынхаа alpha-тай тул зөв газраа л нэмэгдэнэ.

Технийн тэмдэглэл: Blender 5.0-ийн тайзны гаралт олон давхаргат EXR
бичдэггүй тул эдгээр нь компоситорын File Output node-оор гардаг —
`setup_aov()` үүнийг өөрөө угсардаг, гар ажиллагаа шаардлагагүй.

### Blender дотор харах

Скриптийг ажиллуулсны дараа:

1. **Layout** таб руу буц
2. **Numpad 0** — камерын харцаар харна (гарт numpad байхгүй бол
   Edit → Preferences → Input → **Emulate Numpad** асаагаад энгийн 0 товчийг ашигла)
3. Баруун дээд буланд дөрвөн бөмбөлөг байна — хамгийн баруун талынх нь
   **Rendered**. Дарвал гэрэл, материал бүрэн харагдана (эсвэл **Z** → Rendered)
4. GPU асаах: **Render Properties** → Device → **GPU Compute**. Сонголт
   идэвхгүй бол Edit → Preferences → System → Cycles Render Devices →
   CUDA эсвэл OptiX сонгоод картаа чагтал
5. Эргэж тойрох: хулганы **дунд товч** — эргүүлэх, **Shift + дунд** — гулсуулах,
   **дугуй** — ойр/хол. Дотор нь алхаж харах бол **Shift + `** → W/A/S/D, гарахдаа Esc
6. **F12** — бүтэн рендер, рендерийн цонхон дотор **Alt+S** — зураг хадгалах

Гэрэлтүүлэг хүндрэх юм бол Render Properties → Render Engine → **EEVEE**
болговол хурдан эргэнэ (өнгө арай өөр харагдана, харин F12-оор Cycles руу
буцаагаад рендерлэж болно).

## deel.py — монгол үндэсний хувцасны гурван дүр

Лавлагаа зургийн гурван эмэгтэй, тал нутагт. **Гурвуулаа яг 6.00 метр**;
дэлгэц дээр жижиг харагдах нь зайны ялгаанаас болно.

### Зайг хэрхэн тооцоолсон

Лавлагаа зурган дээр дүрсийн өндөр 89.2% / 62.7% / 53.8% байсан. Гурвуулаа
ижил өндөртэй тул зай нь урвуу харьцаатай:

| Дүр | Кадрын өндрийн | Камераас зай | Хэвтээ шилжилт |
|---|---|---|---|
| khalkh (халх хатан) | 89.2% | **16.6 м** | −2.69 м |
| buryat (буриад) | 62.7% | **23.6 м** | +0.09 м |
| uzemchin (үзэмчин) | 53.8% | **27.6 м** | +3.97 м |

Камер (0, −6, 3) дээр хэвтээ харна, 50 мм. Нэг дүрийг хөдөлгөх бол
`CFG["layout"]`-ийн хоёр тоог л сольно.

### Өндрийг яг 6 м болгох

Малгай, эвэр, залаа нийлээд хэд болохыг урьдчилан мэдэх боломжгүй тул
скрипт нь **барьсны дараа хэмжиж, зөрүүгээр нь масштаблана**. Гаралтад
хэмжсэн утга хэвлэгдэнэ:

```
khalkh    барьсан 5.849 -> масштаб 1.0257 -> 6.000 м (зөрүү +0.0 мм)
buryat    барьсан 6.017 -> масштаб 0.9972 -> 6.000 м (зөрүү +0.0 мм)
uzemchin  барьсан 6.026 -> масштаб 0.9956 -> 6.000 м (зөрүү +0.0 мм)
```

`--height 9` гэвэл гурвуулаа 9 метр болно — харьцаа хэвээр.

### Сонголтууд

| Сонголт | Утга |
|---|---|
| `--height 6` | гурван дүрийн өндөр, метрээр |
| `--angle NAME` | `hero` (лавлагааны хүрээ), `trio`, `wide`, `low`, `side`, `close` |
| `--only NAME` | зөвхөн нэг дүр: `khalkh`, `buryat`, `uzemchin` |
| `--wind 0.30` | хормойн салхины хазайлт. 0 = салхигүй |
| `--res`, `--samples`, `--device`, `--render`, `--save-blend` | cockpit.py-тай ижил |

```bash
blender -b -P blender/deel.py -- --angle hero --res 1920x1080 --samples 96 --render out/deel
blender -b -P blender/deel.py -- --save-blend deel-6m.blend
```

### Хаана хүртэл хийгдсэн бэ

**Ажиллаж байгаа нь:** силуэт, өнгөний хуваарилалт, хэтийн харц, өндрийн
нарийвчлал. Алсын кадарт (`hero`, `trio`, `wide`) гурвуулаа танигдана.

**Ажиллахгүй байгаа нь:** ойрын кадар (`close`). Толгойн гоёл, хатгамал,
нүүр нь процедурын хайрцаг-цилиндрээр хийгдсэн тул 6 метрийн дүрийг
ойроос харахад бүдүүлэг. Үүнийг засахад жинхэнэ уран барималын ажил
(sculpt) эсвэл хатгамлын зураг (texture) хэрэгтэй — процедурын код
хүрэхгүй.

### Хэмжээний харьцуулалт — 6 м аврага ба 170 см хүн

`CFG["human"]` нь 1.70 м өндөртэй жирийн хүнийг нэмнэ (`--no-human` гэвэл
хасна). Аврагуудын 1/9 харьцаатай толгойны оронд бодит 1/7.6 харьцаа
өгсөн — эс бөгөөс харьцуулалт өөрөө гажина.

Скрипт гаралтдаа хүснэгт хэвлэнэ:

```
аврага 6.00 м · стандарт хүн 1.70 м · харьцаа 3.53 дахин
хүн аврагын нийт өндрийн 28.3%
  аврагын ankle      0.21 м
  аврагын knee       1.70 м  <- хүний толгойн орой яг энд
  аврагын hip        2.96 м
  аврагын waist      3.34 м
  аврагын shoulder   4.32 м
  аврагын head_top   5.21 м
```

**Санамсаргүй сайхан тоо:** 6 м дүрийн өвдөг яг 1.70 м дээр таарч байна.
Өөрөөр хэлбэл стандарт хүний толгойн орой аврагын өвдөгний малгайд
яг хүрнэ — нэмж тааруулах шаардлагагүй.

Харьцааны мэдрэмж: 28.3% гэдэг нь 170 см насанд хүрэгчийн хажууд
**50 см нялх хүүхэд** зогсохтой тэнцүү (29.4%) — бага насны хүүхэд биш.

| Өнцөг | Юунд |
|---|---|
| `scale` | 135 мм, 46 м зайнаас. Хэтийн гажилтгүй — харьцаа цэвэр уншигдана |
| `line` | `--queue`-тэй хамт: диагональ цуваа, 85 мм. Зай 17.6 / 38.0 / 58.4 м |

```bash
blender -b -P blender/deel.py -- --angle scale --res 1920x1080 --samples 96 --render out/scale
blender -b -P blender/deel.py -- --queue --angle line --render out/line
```

### Хөдөлгөөнт камер (MOVES)

`MOVES` толь дотор гурван хөдөлгөөн. Линз нь хөдөлгөөний турш **тогтмол** —
зум нь камерын хөдөлгөөнийг хуурамч болгодог, хүрээ өөрчлөгдөх нь зөвхөн
камер өөрөө явснаас байх ёстой.

| Нэр | Юу хийдэг | Линз |
|---|---|---|
| `reveal` | Хүний нүдний түвшнээс эхэлж, ухарч өргөгдөн аврагуудыг илчилнэ | 40 мм |
| `orbit` | Эхний аврагыг тойрон нум зурна — радиус 21 м тогтмол, 108° | 55 мм |
| `walk` | Алхаж яваа хүнийг мөрдөж, зэрэг тойрон холдоно | 55 мм |
| `watch` | Холоос даган харах — тогтмол нум + мөрдөх харц | 35 мм |
| `push` | Эгнээний дагуу удаан түрэх (`--queue`-тэй) | 85 мм |

**Нум нь завсрын түлхүүр шаарддаг.** Эхэндээ `orbit` нь зөвхөн хоёр
үзүүрийн түлхүүртэй байсан тул Blender тэднийг шулуунаар холбож, камер
дундуураа 21 м-ээс 11.6 м хүртэл ойртож, эхний аврага кадрыг бүхэлд нь
эзэлж нөгөө хоёрыг халхалдаг байв. Одоо нумыг `frames // 6` алхмаар
түлхүүрлэж, интерполяцийг шугаман болгов — радиус жигд, хүрээ тогтвортой.
Bezier-ээр зөөлрүүлбэл түлхүүр бүрт удааширч чичирдэг тул зөөлрөлтийг
зөвхөн `line` төрөлд үлдээв.

### Хүнийг мөрдөх камер (`walk`)

Хүн эхний аврагын хажуугаас хол аврага руу алхана, камер зэрэг тойрон
холдоно. Хүн **дэлгэцийн доод хэсэгт голлож** үлдэнэ — аврагууд дээгүүр
нь өндийж харагдана.

Үүний түлхүүр нь **харцыг хүнээс дээш тооцоолох** явдал. Хүн рүү шууд
харвал тэр кадрын яг голд (ndc_y = 0.5) буудаг. Хүссэн `ndc_y`-д барихын
тулд харц нь хүнээс `(0.5 − ndc_y) / k` × зай дээш байх ёстой, энд
`k = (линз / 36) × харьцаа`. Камер холдох тусам энэ шилжилт өсдөг тул
түлхүүр бүрт дахин бодогдоно.

**Зай — кино театрын эхний эгнээ.** Хүний зам нь аврагуудын шугамаас
**13.5 м перпендикуляр** зайд. 6 м аврагыг 2.39:1 дэлгэц гэж үзвэл
(14.3 м өргөн) 13.5 м дээрээс хэвтээ **56°**, босоо 25° өнцгөөр харагдана.
Кино театрын эхний эгнээ ихэвчлэн 50–60° хэвтээ өнцгийн бүсэд байдаг
(SMPTE сүүлийн эгнээ ≥ 30°, THX ≥ 36°). Замын турш хамгийн ойрын аврага
13.50–14.51 м.

**Камерын нум ТОГТМОЛ төвтэй.** Нумыг хөдөлж яваа хүн дээр төвлөрүүлбэл
зогсолт дуусах мөчид камер гэнэт үсэрнэ — хүн тэр хооронд 2 м явчихсан
байна. Тиймээс камер замаараа явна, зөвхөн харц нь хүнийг дагана
(бодит зураг авалт ч яг ийм). Шалгав: зогсолтын зааг дээр (фрейм 119→121)
камерын шилжилт 0.019 м — үсрэлт алга.

Шалгав — хүний дэлгэц дэх байрлал 30 секундын турш:

| Фрейм | Сек | Хүний NDC | Камер хүртэл | Ойрын аврага |
|---|---|---|---|---|
| 1 | 0.0 | (0.500, 0.279) | 17.8 м | 13.50 м |
| 300 | 12.5 | (0.500, 0.280) | 25.4 м | 14.51 м |
| 720 | 30.0 | (0.500, 0.280) | 35.7 м | 13.50 м |

Зорилт 0.280, хамгийн том зөрүү **0.003**. Гурван аврага бүх хугацаанд
кадарт үлдэнэ (NDC x нь 0.28–0.83).

Алхалт: 12.81 м / 30 сек = **0.43 м/с**, 21 алхам, **зогсохгүй**. Хөл нь
ташааны голд (`HM_HIP_*`) эцэглэсэн — гол байхгүй бол объектыг өөрийнх нь
төвөөр эргүүлэхэд хөл дундуураа тасарч эргэнэ.

`CFG["walk"]["hold"]` нь хүний зогсолт, `MOVES["walk"]["hold"]` нь
камерынх — **хоёр тусдаа**. Одоогийн тохиргоо: хүн 0 (зогсохгүй), камер
0.1667 (эхний 5 сек байрандаа, харин харц нь дагана — энэ нь пан).

**Хугацаа ба хурд** (`reveal`, 11.98 м зам):

| `--frames` | Хугацаа | Хурд |
|---|---|---|
| 96 | 4 сек | 3.00 м/с — шуурхай |
| 192 | 8 сек | 1.50 м/с — тайван |
| 720 | 30 сек | 0.40 м/с — ёслолын, маш удаан |

```bash
# ганц кадар шалгах
blender -b -P blender/deel.py -- --move orbit --frames 720 --frame 360 --render out/k

# бүтэн дараалал
blender -b -P blender/deel.py -- --move reveal --frames 720 --anim \
        --res 1920x1080 --samples 96 --render out/reveal/f
```

`--frames` нь хөдөлгөөний урт, `--anim` нь дарааллыг рендерлэх туг — хоёр
өөр зүйл. Нэг тугт нийлүүлсэн байсан тул `--frame`-тэй зөрчилдөж, ганц
кадар хүсэхэд бүтэн дараалал рендерлэдэг байв.

### Холоос даган харах (`watch`) ба хүний хэмжээний хязгаар

`orbit`-ын тогтмол нум дээр `walk`-ийн мөрдөх харцыг нийлүүлсэн: камер
хүний замын дундыг тойрон 42 → 54 м зайд, 4.2 → 7.0 м өндөрт явна, харц
нь алхаж яваа хүнийг дагана.

**Геометрийн хатуу хязгаар.** Хүн кадрын голд, гурван аврага кадарт
байхыг нэгэн зэрэг шаардвал хүний дэлгэц дэх хэмжээ **8.1%-иас хэтрэхгүй**
— линзээс үл хамааран. Учир нь:

```
хүнээс хамгийн хол аврага хүртэл 18.6 м
кадарт багтах нөхцөл:  18.6 / R < 18 / линз   ->   R > 1.033 x линз
хүний хэмжээ = 1.70 x линз / (R x 20.25) < 8.1%
```

Линз уртсахад шаардах радиус нь яг адил харьцаагаар өсдөг тул харьцаа
өөрчлөгдөхгүй:

| Линз | Хамгийн бага радиус | Хүний хамгийн том хэмжээ |
|---|---|---|
| 28 мм | 28.9 м | 8.1% |
| 50 мм | 51.7 м | 8.1% |
| 135 мм | 139.5 м | 8.1% |

Хүнийг томруулахын тулд гурван нөхцлийн **нэгийг нь орхих ёстой**:

1. **Бүх 3 аврага кадарт** — орхивол зөвхөн 1–2 аврага үлдэж хүн 13–20%
2. **Хүн кадрын голд** — орхивол хүнийг хажуу тийш болгож бүлгийг голд
3. **13.5 м зай** — орхивол хүнийг аврага руу ойртуулна

### Кино театрын дүрмээр тохируулсан watch камер

`--move watch --frames 720` (30 сек). Гурван үе:

| Үе | Фрейм | Хугацаа | Камер | Хүн кадрын |
|---|---|---|---|---|
| Зогсолт | 1–120 | 5.0 сек | 42 м, 3.20 м өндөрт байрандаа; зөвхөн ХАРЦ нь хүнийг дагана (пан) | 6.2% |
| Нум | 120–600 | 20.0 сек | 42 → 54 м, 3.20 → 4.80 м, 70° тойрно | 6.2 → 5.7% |
| **Ойртолт** | 600–720 | 5.0 сек | 54 → 24 м, 4.80 → **1.80 м** (хүний нүдний түвшин), +12° | 5.7 → **15.0%** |

**Хэрэглэсэн дүрмүүд ба хэмжилт**

1. **Аварга юмыг ҮРГЭЛЖ доороос** — камерын өндөр 6 м-ээс хэзээ ч
   хэтрэхгүй. Өмнөх 7.00 м дээр аврагын орой тэнгэрийн хаяанаас 0.028 ndc
   ДООГУУР унаж, бид тэднийг дээрээс доош харж байсан. Одоо 4.80 м дээд
   цэгт нь ч орой хаяанаас +0.030, эхлэлд +0.076 ДЭЭШ гарна.
2. **Гуравны дүрэм** — `ndc_y` 0.30 → 0.333. Хүн яг доод гуравны нэг дээр,
   тэнгэрийн хаяа 0.39–0.47 буюу төвөөс доош; аврагууд хаяаг эвдэнэ.
3. **180°-ын шугам** — камер хүн ↔ аврагын шугамын БАРУУН талд 30 секундын
   турш үлдэнэ (хэмжсэн тэмдэг: −255 → −127, огт эргээгүй).
4. **Салалт (дүрсүүд бие биенээ халхлахгүй)** — ойртолтын төгсгөлийн өнцгийг
   `az2 = 16°` гэж сонгосон нь хүнийг khalkh (x 0.43) ба buryat (x 0.61)
   хоёрын ЗАВСАРТ гаргадаг (зай +0.030 ndc). `az2 = 21.5°` дээр khalkh
   x 0.50 дээр буюу яг хүний дээр ирж, хүн хормой дээр алга болно.
5. **Хурд тасрахгүй** — `ease_from(u, v0)` Эрмитийн куб муруй. Суваг бүрийн
   `v0`-г нумын үеийн өөрийнх нь хурдаар өгнө:
   `v0 = (v1 − v0_арын) × (ойртолтын урт / нумын урт) / (v2 − v1)`.
   Үүнгүйгээр (энгийн smoothstep) заагт хурд 3.35 → 2.27 м/с унаж,
   нэг фреймд 1.09 м/с үсрэлт гарч байв; одоо 3.35 → 3.31 м/с, дээд
   үсрэлт 0.46 м/с. Радиусын `v0` сөрөг — камер заагийн дараа бага зэрэг
   холдсоор байгаад л эргэж ойртоно, жинхэнэ кран яг ингэж явдаг.
6. **Төгсгөлд намжина** — сүүлийн фреймийн хурд 0.31 м/с. Хөдөлгөөний
   дундуур тасарсан мэт кадраар дуусахгүй; Seedance 2.5 сүүлийн фреймийг
   лавлагаа болгон уншдаг тул энэ нь чухал.

Хурдны профиль: 3.3 м/с (нум) → 9.4 м/с (ойртолтын дунд, фрейм 659)
→ 0.31 м/с (төгсгөл). Нийт зам 92.6 м.

Тохируулах түлхүүрүүд `MOVES["watch"]`-д: `close` (ойртолтын эзлэх хувь,
0 бол ойртолтгүй), `az2` / `r2` / `z2` (төгсгөлийн өнцөг, радиус, өндөр).

## impact.py — солир ачааны хөлөг рүү мөргөх нь

Камер СОЛИР дээр суусан (POV). Хийн аварга гаригийн солирын бүслүүр
дотор алсаас "0110" ачааны хөлгийг олж хараад, тогтмол хурдаар аажуухан
ойртоно. **Мөргөлтийг харуулахгүй** — 5.3 секундын өмнө тасална.

```
blender -b -P blender/impact.py -- --angle pov --frames 720 \
    --res 1920x1080 --samples 96 --device GPU --anim --render out/impact
```

### Мөргөлтийг яагаад харуулахгүй вэ

Хичкокийн "ширээн доорх бөмбөг": үзэгч юу болохыг мэдэж байгаа тул
айдас дэлбэрэлтээс биш, ХҮЛЭЭЛТЭЭС үүснэ. Сүүлийн кадарт хөлөг кадрын
90%-ийг эзэлж, солир цонхны эгнээ рүү чиглэсэн байхад тасална — тэр
хурдаараа 5.3 секундын дараа мөргөнө. Дараагийн шот нь `cockpit.py`-ийн
гүүр (сэрэмжлүүлэг асах) байж болно.

### Хэмнэл: зөвхөн хоёр зайн харьцаа

Солир бол хөдөлгүүргүй чулуу — хурд ТОГТМОЛ. Дэлгэц дэх хэмжээ 1/R-ээр
өсөх тул хэмнэлийг зөвхөн эхлэх/тасалах зайн харьцаа тодорхойлно:

| эхлэх → тасалах | харьцаа | хурд | хөлөг | сүүлийн 3 сек | тасалсны дараа |
|---|---|---|---|---|---|
| 1400 → 23 м (өмнөх) | 60.9× | 46 м/с | 16.7% → 1014% | **7.0× дэлбэрнэ** | мөргөлт харагдана |
| **1600 → 260 м** | **6.2×** | 45 м/с | **14.6% → 90%** | **1.52×** | 5.3 сек |
| 1600 → 180 м | 8.9× | 47 м/с | 14.6% → 130% | 1.79× | 3.3 сек |
| 1200 → 260 м | 4.6× | 31 м/с | 19.4% → 90% | 1.36× | 7.6 сек |

`--dist` ба `--end`-ээр өөрчилнө.

| сек | зай | хөлөг кадрын өргөний |
|---|---|---|
| 0.0 | 1600 м | 14.6% |
| 15.0 | 930 м | 25.1% |
| 21.0 | 662 м | 35.2% |
| 25.5 | 461 м | 50.6% |
| 27.9 | 354 м | 66.0% |
| 30.0 | 260 м | 89.7% — ТАСАЛНА |

Хурдыг мэдрүүлдэг зүйл нь хөлөг биш — хажуугаар өнгөрөх ойрын
чулуунуудын ПАРАЛЛАКС. 6 чулууг замын дагуу тодорхой секундэд 34–150 м
зайд ЗОРИУД байрлуулсан. Хөлгийн өмнө, түүний өнцгийн хүрээнд орж
халхлах дэвсгэрийн чулууг өөр байрлалд дахин сонгоно.

### Хийн аварга гариг ба бүслүүр

**Гариг** кадрын баруун доод буланд, 20° радиустай. Од кадр дотор байгаа
тул кадр доторх ЯМАР Ч гариг хавирган сар хэлбэртэй байна (фазын өнцөг
>120°) — физик. Одоос хамгийн хол булан нь хамгийн том хавирга өгнө:
фазын өнцөг 128.5°, гэрэлтсэн хэсэг 19%. Хөлөг сүүлийн 5 секундэд
гаригийн хавирган сарны өмнө харанхуй дүрсээр тодорно.

**Бүслүүр** — бид цагирагийн ДОТОР байгаа тул цагираг тэнгэрийг бүтэн
тойрсон их тойрог (Сүүн зам шиг) болж харагдана. World shader-т
|туяа·n| -ээр Гауссын зурвас зурсан; одны зүгт тоос урагшаа сарнидаг
тул тэр хэсэг илүү гэрэлтэнэ. Гаригийн зурвасууд цагирагтай ЗЭРЭГЦЭЭ
(цагираг экваторын хавтгайд оршдог). Дэвсгэрийн чулуунуудыг ч энэ
хавтгай руу 65% хавтгайруулсан.

Гариг ба од нь камерын БАЙРЛАЛЫГ дагадаг `SKY` объектод холбогдсон —
эргэлтийг биш. Хязгааргүй алсад байгаа мэт: камер эргэхэд кадр дотор
шилжинэ, харин 1340 м явахад параллакс үүсэхгүй.

### Гэрлийн гурван урхи (гаригийн шөнийн тал 0.094 → 0.0075)

Гариг эхэндээ БҮТЭН гэрэлтэй харагдаж байв. Гэрэл бүрийг ээлжлэн
унтраан хэмжиж гурван шалтгааныг олов:

1. **Дүүргэгч гэрэл.** Хөлгийн сүүдэр талд зориулсан кино заль нь 5%
   альбедотой хөлөг дээр бараг мэдэгдэхгүй ч 60% альбедотой гариг дээр
   12–16 дахин тод тусна. Light linking-ээр гаригийг хасав.
2. **Одны бөмбөрцөг гэрлийн эх үүсвэр болсон.** Бөмбөрцөг камераас 62 км,
   гариг 150 км-т тул гаригаас харахад "од" камерын талд байрлаж шөнийн
   талыг урдаас гэрэлтүүлж байв. Одыг бусад объектын туяанд үл үзэгдэх
   болгов (`visible_diffuse = False` …) — камерт харагдсаар.
3. **Агаар мандлын бүрхүүл гаригийг ДОТРООС гэрэлтүүлсэн.** Гадаргуугаас
   гарсан туяа бүрхүүлийн дотор талыг цохиход Cycles нормалийг туяа руу
   эргүүлдэг тул "гэрэлтсэн тал" маск урвуу болж шөнийн талд асдаг байв
   (шөнийн талын гэрлийн 84%). Бүрхүүлийг зөвхөн камерт харагдуулав.

### Эзэлхүүний гэрэлтэлт = МЕТР ТУТАМД

Тийрэлтийн конус эзэлхүүний гэрэлтэлттэй. Хүч нь метр тутмын утга тул
харааны шугамын уртаар хуримтлагдана. Ар талаас налуу харахад шугам
конусын дагуу ~18 м явж, 0.9/м нь ~16 болж цагаан шаантаг үүсгэж байв.
Тэнхлэгээс радиусаар бүдгэрүүлж (ханын хурц ирмэг арилна), хүчийг 1.2
болгов. Мөн хөдөлгүүрийн цөмийг 48 → 18 болгож, одны цацрагийн босгыг
60 болгосон — эс бөгөөс цөм нь 70 м урт цэнхэр туяа үүсгэдэг байв.

Одны цацраг нь 2 салаа, хэвтээ (анаморф) — лавлагаа зурагтай ижил.

### Ирэх чиглэл яагаад ийм вэ

`CFG["from"] = (-0.55, 0.76, -0.34)` — гурван шаардлагыг нэгэн зэрэг
хангасан цорын ганц муж:

| бүрэлдэхүүн | яагаад |
|---|---|
| +Y (баруун хажуу) | хамар дэлгэцийн ЗҮҮН талд — лавлагаа зурагтай ижил |
| −X (ар тал) | хөдөлгүүрийн хөх гялбаа бидэн лүү харна |
| −Z (доор) | хөлгийг доороос дээш харна — илүү аварга |

Тэнхлэгээс 56.6°. Энэ өнцөг чухал: 72° дээр хөдөлгүүрийн ам нарийн
зураас болж гялбаа бүхэлдээ алга болдог; 44° дээр гялбаа сайхан ч хөлөг
богиноссон мэт болно.

### Хүрээлэл

Хөлгийн төв эхэндээ ndc (0.60, 0.43) — төвөөс баруун-доош, учир нь од
зүүн дээд буланд байгаа тул тэнцвэр хангана. Төгсгөлд мөргөх цэг
(0.50, 0.47) руу шилжинэ. Камер тогтмол 35 мм — зум бол хуурамч
хөдөлгөөн.

Чулуу эргэлддэг тул камер 11° налж эргэнэ. Жинхэнэ солир бол
хаашаа ч эргэлддэг — бүрэн эргэлт өгвөл хөлөг кадраас гарч, шот
утгагүй болно. Тиймээс эргэлтийг зөвхөн ROLL болгон хязгаарласан;
энэ нь тайзны бодит бус, харин уншигддаг шийдэл.

### Blender 5.0-ийн хоёр урхи (энд тааралдсан)

1. **Компоновк.** `CompositorNodeComposite` зангилаа УСТСАН. Шинэ
   `scene.compositing_node_group` нь рендерийн үр дүнг бүлгийн
   ОРОЛТООС авдаггүй — авна гэж бодвол бүрэн ХАР, ил тод кадар гарна.
   Бүлэг дотор `CompositorNodeRLayers` тавьж Group Output руу холбоно.
   Мөн Glare-ийн `glare_type` шинж чанар байхгүй болж, "Type" нэртэй
   ЦЭСЭН СОКЕТ болсон (`node.inputs["Type"].default_value = "Streaks"`).
2. **Зангилаа устгах.** `for n in list(nt.nodes): if n is not out:
   nt.nodes.remove(n)` гэвэл БҮГДИЙГ нь устгана — устгасны дараа
   боодлууд хүчингүй болж `is not` харьцуулалт таарахаа болино.
   Нэрээр нь устгах хэрэгтэй.

### Шотын урт: 8 / 10 / 30 секунд

`--frames 192` (8 сек), `--frames 240` (10 сек), `--frames 720` (30 сек,
анхдагч). Зам ижил (1600 → 260 м) тул хурд л өөрчлөгдөнө:

| урт | хурд | сүүлийн 3 сек | тасалсны дараа мөргөлт хүртэл |
|---|---|---|---|
| 8 сек | 168 м/с | 2.93× | 1.4 сек |
| 10 сек | 134 м/с | 2.55× | 1.8 сек |
| **30 сек** | **45 м/с** | **1.52×** | **5.3 сек** |

Богино шот дээр нэг зүйл автоматаар засагдана. Өнгөрөгч чулуунуудын
хажуугийн зайг `k = sqrt(30 / секунд)`-аар томруулна (8 сек дээр 1.94
дахин). Шалтгаан: 34 м-ийн зайд өнгөрөх чулуу 30 секундын шот дээр
78°/сек-ээр сайхан шуурдаг бол, 8 секунд дээр хурд 3.7 дахин нэмэгдэж
293°/сек болно — чулуу 4 фреймд шувт өнгөрч, хурдны мэдрэмж биш зүгээр
нэг алдаа мэт харагдана. Шугаман засвар (×3.75) хэтэрхий холдуулж
чулууг үл үзэгдэх болгодог тул язгуур авав.

## Blender-ийн хувилбар: 5.2.2 LTS (үндсэн)

2026-09-26-нд 5.0.1-ээс **5.2.2 LTS** руу шилжив. LTS нь 2 жил засвар
авдаг тул урт төсөлд тохиромжтой.

Cloud орчинд `blender/run.sh` нь 5.2.2-ийг ажиллуулна. Container session
бүрт шинээр үүсдэг тул `bpylib52/` алга байвал өөрөө суулгана (хоосон
хавтсанд туршихад 17 сек). Өөр хувилбар хэрэгтэй бол:
`BPY_VERSION=5.0.1 BPY_LIB=./bpylib BPY_PYTHON=python3.11 blender/run.sh …`

| хавтас | bpy | Python | төлөв |
|---|---|---|---|
| `bpylib52/` | **5.2.2 LTS** | 3.13 | үндсэн — `blender/run.sh` |
| `bpylib/` | 5.0.1 | 3.11 | нөөц, харьцуулалтад |

5.1-ээс хойшхи бүх `bpy` wheel **Python 3.13** шаарддаг
(`requires_python: ==3.13.*`). Тиймээс `pip index versions bpy` нь
Python 3.11 дээр 5.0.1-ээс цааш юу ч харуулахгүй — шинэ хувилбар байхгүй
мэт хуурдаг. PyPI-ийн JSON-оос шалгах хэрэгтэй.

Суулгах (≈30 сек, 995 МБ):

```
python3.13 -m pip install --target ./bpylib52 bpy==5.2.2
```

**Шалгасан (640×360, 16 дээж):** гурван скрипт 5.2.2 дээр алдаагүй
ажилласан. 5.0.1-тэй харьцуулахад 0.05-аас их зөрүүтэй пиксел impact
0.33%, deel 0.22%, cockpit 0.94% — энэ нь дээжийн шуугиан, ялгаа биш.
5.0-д тааралдсан бүх API өөрчлөлт (compositor бүлэг + RLayers, Glare-ийн
"Type" сокет, `media_type='VIDEO'`) 5.2-т хэвээр.

**Шинэ суулгасан Blender дээр НЭГ УДАА:** Edit → Preferences → System →
Cycles Render Devices → **OptiX** (NVIDIA RTX) / CUDA (хуучин NVIDIA) /
HIP (AMD) / Metal (Mac) сонгож GPU-гээ чагтлаад Save Preferences.
Анхдагч нь "None" — тэгвэл `.blend` дотор GPU гэж бичсэн ч Blender
чимээгүйхэн CPU-гаар рендерлэнэ. Командын мөрнөөс (`blender -b -P …`)
ажиллуулахад гурван скрипт хоёулаа GPU-г өөрсдөө асаана (`pick_device`).

**`.blend` файлууд** 5.2.2-оор дахин гаргагдсан. Blender 5.2 дээр
нээнэ; 5.0 дээр нээвэл "шинэ хувилбараар хадгалсан" гэсэн анхааруулга
гарна.

**Blender 6.0-д** `Material.use_nodes`, `World.use_nodes` устана
(5.2 дээр DeprecationWarning гардаг). 6.0 гарахад эдгээр мөрийг засна.
