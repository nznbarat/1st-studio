# Видео → 3D render (багц хөрвүүлэгч)

Хавтас дүүрэн mp4‑г **Seedance 2.5**‑ийн *reference-to-video* горимоор нэг ижил
„3D render" промтоор дамжуулж, `output/` дотор **эх нэрээр нь** хадгална.

```
input/                        output/
  ангилал_01.mp4   ─┐          ангилал_01.mp4
  ангилал_02.mp4    ├─ ffmpeg ─→ Seedance 2.5 ─→ ffmpeg ─→  ангилал_02.mp4
  гудамж.mov       ─┘  хэрчих     (@Video1)       наах       гудамж.mp4
```

Загвар эх видеог **хөдөлгөөн, камер, монтажийн лавлагаа** болгон авч, зөвхөн
дүрслэлийг нь 3D render болгон солино.

---

## 1. Шаардлага

| Юу | Тайлбар |
|---|---|
| Python 3.9+ | стандарт сан + нэг provider |
| **ffmpeg / ffprobe** | хэрчих, наах, урт хэмжих — заавал |
| API түлхүүр | fal.ai эсвэл Replicate |

```bash
# ffmpeg
sudo apt install ffmpeg        # Linux
brew install ffmpeg            # macOS

# Python сан — аль нэгийг
pip install fal-client         # fal.ai (санал болгож байна)
pip install replicate          # Replicate
```

ffmpeg‑ийг PATH‑д нэмэхгүйгээр заах бол:
`export V2V3D_FFMPEG=/зам/ffmpeg` (мөн `V2V3D_FFPROBE`).

## 2. Түлхүүр тохируулах

```bash
export FAL_KEY="xxxxxxxx:yyyyyyyy"        # fal.ai
# эсвэл
export REPLICATE_API_TOKEN="r8_xxxx"      # Replicate
```

## 3. Хурдан эхлэл

```bash
cd video-to-3d

python3 -m v2v3d styles                              # бэлэн загварууд
python3 -m v2v3d plan  -i ~/videos                   # өртөг, төлөвлөгөө (үнэгүй)
python3 -m v2v3d run   -i ~/videos -o ./output       # хөрвүүлэх
```

Эхлээд **1–2 файл дээр туршаарай**:

```bash
python3 -m v2v3d run -i ~/videos --limit 1 --resolution 480p
```

---

## 4. Командууд

| Команд | Юу хийх |
|---|---|
| `run` | багцыг хөрвүүлнэ |
| `plan` | файл бүрийн хэсэглэлт, ойролцоо өртгийг харуулна (API дуудахгүй) |
| `styles` | бэлэн 10 загварыг жагсаана |
| `schema` | provider‑ийн **бодит** оролтын талбаруудыг татаж хэвлэнэ |

### Гол сонголтууд

| Сонголт | Анхдагч | Тайлбар |
|---|---|---|
| `-i, --input` | — | оролтын хавтас (заавал) |
| `-o, --output` | `./output` | гаралтын хавтас |
| `--style` | `3d-render` | загварын нэр |
| `--prompt` / `--prompt-file` | — | өөрийн промт (загварыг орлоно) |
| `--extra-prompt` | — | промтын төгсгөлд нэмэх өгүүлбэр |
| `--provider` | `fal` | `fal` \| `replicate` |
| `--endpoint` | загвараас | endpoint‑ыг гараар дарах |
| `--resolution` | `720p` | `480p` \| `720p` \| `1080p` |
| `--duration` | `auto` | `auto` = эх хэсгийн урттай тэнцүү, эсвэл 4–30 |
| `--aspect-ratio` | `auto` | `16:9`, `9:16`, `1:1` … |
| `--audio` | унтраалттай | дуу үүсгэх |
| `--seed` | — | давтагдах үр дүнд |
| `--style-image` | — | загварын лавлагаа зураг (олон удаа) |
| `--long-video` | `segment` | `segment` \| `trim` \| `whole` \| `skip` |
| `--chunk-seconds` | `10` | хэсэг бүрийн урт (4–30) |
| `--reencode-split` | унтраалттай | илүү нарийн тасалт (удаан) |
| `-r, --recursive` | унтраалттай | дэд хавтсуудыг ч хамруулна |
| `--ext` | mp4 mov m4v mkv webm | хамрах өргөтгөлүүд |
| `-c, --concurrency` | `2` | зэрэг ажиллах файлын тоо |
| `--retries` | `3` | алдаанд дахин оролдох тоо |
| `--limit` | — | эхний N файл (турших) |
| `--overwrite` | унтраалттай | байгаа гаралтыг дарж бичих |
| `--dry-run` | унтраалттай | `plan`‑тай ижил |
| `--keep-work` | унтраалттай | түр хэсгүүдийг үлдээх (алдаа хайхад) |
| `--set К=У` | — | payload‑д нэмэлт талбар шууд оруулах |

## 5. Загварууд

| id | Төрх |
|---|---|
| `3d-render` | Ерөнхий стилжүүлсэн 3D CGI (**анхдагч**) |
| `pixar` | Том студийн хүүхэлдэйн кино |
| `clay` | Шавар / stop-motion |
| `lowpoly` | Цөөн өнцөгт, хавтгай өнгө |
| `blockout` | Материалгүй саарал previz загвар |
| `blender-eevee` | Blender EEVEE render |
| `unreal` | Unreal Engine 5 кино |
| `gsplat` | Gaussian splat / фотограмметрийн төрх |
| `wireframe` | Торлог бүтэц |
| `toon` | Cel-shaded аниме 3D |

Промтууд `v2v3d/styles.json` дотор — засаж, шинээр нэмж болно. Промт бүр
`@Video1` лавлагааг **заавал** агуулна; байхгүй бол хөтөлбөр өөрөө урд нь нэмнэ
(эс бөгөөс загвар оруулсан видеог үл тоож, шинэ видео зохиочихно).

Өөрийн промт:

```bash
python3 -m v2v3d run -i ~/videos \
  --prompt "@Video1 — re-render as brushed metal miniature diorama, keep camera and timing"
```

## 6. Урт видеог хэрхэн зохицуулах вэ

Seedance 2.5‑ийн видео лавлагаа нь **нийт ~30 секундээр**, нэг гаралт нь
**4–30 секундээр** хязгаарлагдана. Тиймээс:

- `--long-video segment` (анхдагч) — `--chunk-seconds` тутам хэрчээд, хэсэг
  бүрийг тусад нь хөрвүүлж, эцэст нь ffmpeg‑ээр буцаан наана.
- `--long-video trim` — зөвхөн эхний 30 секундыг авна.
- `--long-video whole` — бүтнээр нь (30с‑ээс урт бол алдаа).
- `--long-video skip` — урт файлыг алгасна.

`--duration auto` үед хэсэг бүрийн гаралт эх хэсгийнхээ урттай тэнцүү болж,
монтажийн хэмнэл хадгалагдана.

**Хэсгүүдийн хооронд төрх зөрөхөөс сэргийлэх:**

```bash
python3 -m v2v3d run -i ~/videos \
  --chunk-seconds 15 \          # цөөн хэсэг = цөөн шилжилт
  --seed 12345 \                # давтагдах үр дүн
  --style-image ./style_ref.png # нийтлэг өнгө, материалын лавлагаа
```

## 7. Өртөг

`plan` команд ойролцоо тооцоог хэвлэнэ. fal.ai‑ийн 2026‑08‑ны үнээр
(видео лавлагаатай үед лавлагааны секунд ч тооцогдоод нийт дүн 0.6‑аар үржинэ):

| Нягтрал | ≈ 1 секунд тутам |
|---|---|
| 480p | ≈ $0.13 |
| 720p | ≈ $0.28 |

10 секундын клип 720p‑ээр ≈ **$3.4**. Тиймээс эхлээд `--limit 1 --resolution 480p`
дээр туршиж, промтоо тааруулсны дараа бүх багцаа явуулна уу. Тооцоо нь
чиглүүлэх зорилготой — жинхэнэ дүнг provider‑ийн самбараас хараарай.

## 8. Гаралт, дахин ажиллуулалт

- Гаралт: `output/<эх нэр>.mp4` (`-r` үед дэд хавтасны бүтэц ч хадгалагдана).
- `output/_manifest.json` — файл бүрийн төлөв, хэсгийн тоо, өртөг, алдаа.
- Дахин ажиллуулахад **бэлэн болсон файлууд алгасагдана** — тасалдсан багцыг
  ижил тушаалаар үргэлжлүүлж болно. Дахин хийлгэх бол `--overwrite`.
- Түр файлууд `output/.work/` дотор, амжилттай болмогц устана (`--keep-work`).

## 9. API схем өөрчлөгдвөл

Талбарын нэрс (`video_urls`, `image_urls`, `duration` …) нь fal.ai‑ийн
2026‑08‑ны бичиг баримтаас авсан. Provider схемээ шинэчилбэл:

```bash
python3 -m v2v3d schema --provider fal        # бодит талбаруудыг хэвлэнэ
python3 -m v2v3d schema --provider replicate
```

Дараа нь:

- нэмэлт талбар — `--set camera_fixed=true`
- endpoint солих — `--endpoint bytedance/seedance-2.5/reference-to-video`
- Replicate дээрх нэр өөр бол —
  `export V2V3D_RP_VIDEO_FIELD=video_references` (мөн `..._IMAGE_FIELD`,
  `..._DURATION_FIELD`, `..._RESOLUTION_FIELD`, `..._ASPECT_FIELD`, `..._SEED_FIELD`)

## 10. Тест

```bash
python3 -m unittest discover -s tests -v
```

40 тест — сүлжээ, API түлхүүр шаардахгүй. ffmpeg байвал хуурамч provider‑тэй
бүтэн урсгалыг (хэрчих → хөрвүүлэх → наах) шалгана.

## 11. Алдаа шийдэх

| Шинж тэмдэг | Шалтгаан / шийдэл |
|---|---|
| `ffmpeg/ffprobe олдсонгүй` | ffmpeg суулгах эсвэл `V2V3D_FFMPEG` заах |
| `FAL_KEY орчны хувьсагч алга` | түлхүүрээ export хийх |
| `хариунаас видеоны хаяг олдсонгүй` | схем өөрчлөгдсөн — `schema` командыг үзнэ үү |
| Гаралт эх видеонд огт төстэй биш | промтод `@Video1` байгаа эсэх, `--chunk-seconds`‑ыг багасгах |
| Хэсэг хооронд өнгө үсэрч байна | `--seed`, `--style-image` нэмэх, `--chunk-seconds` ихэсгэх |
| `422` / талбарын алдаа | `--set`‑ээр талбар нэмэх, эсвэл `schema`‑гаар нэрсийг шалгах |

## Хавсралт: гурван өөр зам

Таны дурдсан гурван эх сурвалж өөр өөр асуудал шийддэг:

| Арга | Юу гардаг | Хэзээ |
|---|---|---|
| **Seedance V2V** (энэ хэрэгсэл) | 3D render **төрхтэй видео** | Хурдан, олон клип, дүрслэлийн загвар л хэрэгтэй үед |
| **gsplat / COLMAP-free 3DGS** | Жинхэнэ **3D дүрслэл** (splat), шинэ өнцгөөс дахин render хийж болно | Камераа өөрчлөх, орчинг дахин ашиглах шаардлагатай үед |
| **Blender + Python** | Бүрэн хяналттай **программчилсан render** | Гэрэл, материал, камерыг кадр тутам нарийн удирдах үед |

Энэ хэрэгсэл эхнийхийг нь автоматжуулна: жинхэнэ геометр үүсгэхгүй, харин
хөдөлгөөн, камерын хөдөлгөөнийг хадгалж дүрслэлийг нь солино. Хэрэв дараа нь
3DGS эсвэл Blender рүү шилжих бол `--style blockout` (материалгүй саарал
загвар) нь previz шатанд хамгийн ойр үр дүн өгнө.
