Бүх зүйл зөвхөн энэ хөтөч дотор хадгалагдана. Сервер шаардахгүй, түлхүүр хаашаа ч илгээгдэхгүй — Google-ийн API-аас өөр рүү.

Хувийн хэрэглээнд зориулсан. Энэ файлыг олон нийтэд нээлттэй байрлуулбал API түлхүүр хөтчийн код дотор ил гарна. Зөвхөн өөрийн компьютер дээрээ ажиллуул.
aistudio.google.com/apikey дээрээс үнэгүй авна. Live Translate preview үед төлбөргүй ч хязгаартай.
Анхдагч: gemini-3.5-live-translate-preview. Preview нэр өөрчлөгдвөл энд шинэчилнэ.
elevenlabs.io → Profile → API Keys. Scribe (яриа→текст) ба TTS (текст→яриа) хоёуланд нь хэрэглэнэ.
ElevenLabs → Voices → сонгосон хоолойн Voice ID. Өөрийн хувилсан хоолойг ч тавьж болно.
eleven_v3 — хамгийн сайн чанар, монголыг жагсаалтад байхгүй ч уншдаг. eleven_flash_v2_5 — хурдан ч чанар нь буурна. Гаралтын формат: PCM боломжтой бол PCM, үгүй бол MP3 руу өөрөө шилжинэ.
Gemini сонговол нэмэлт түлхүүр хэрэггүй — ⚙ дээд талын Gemini түлхүүрийг дахин ашиглана. Загварыг нь жагсаалтаас автоматаар сонгоно.
Богино өгүүлбэр орчуулахад Haiku ойролцоогоор 5 дахин хямд бөгөөд саатал багатай. Урлаг, хэлц үг элбэг яриа бол Opus давуу.
ElevenLabs орчуулга хийдэггүй тул дунд шатанд Claude ажиллана. npm run serve-ээр ажиллуулж ANTHROPIC_API_KEY тохируулсан бол энэ талбар хоосон байж болно.
